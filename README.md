# Portfolio - Wafa Mzoughi

**Ingénieure Génie Logiciel** - Flutter, Laravel, Odoo, Angular, React, Node.js.

Site vitrine mono-page. Sans étape de build, sans dépendances - HTML, CSS, JS vanilla.

## Structure

- `index.html` - site mono-page (Accueil, À propos, Expérience, Compétences, Projets, Formation, Contact)
- `assets/css/main.css` - thème sombre/clair
- `assets/js/main.js` - bascule de thème, animations au scroll, état de nav, menu mobile
- `assets/pdf/CV_WafaMzoughi.pdf` - CV téléchargeable

## Déploiement

Push sur `main` - GitHub Pages sert la racine du dépôt automatiquement.
